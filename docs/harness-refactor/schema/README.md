# 唯一目标表结构
只使用 `target.sql.reference`。这是当前设计的字段与约束参考，**不是可直接执行的自动迁移**。
先在本地记录 `SHOW CREATE TABLE agent_session/repository/branch`、已执行Flyway版本、列字符集/排序规则；然后在新迁移中只添加缺失字段，迁移旧数据，再补约束。不得全量执行已有表的CREATE或重复ADD COLUMN。
本轮合并后没有第二份PR DDL，没有自动复制为下一V号并声称可执行的脚本。旧Session单值base/head/branch仅可保留历史读取；当前写入从agent_workline读取。
外键需与真实旧库类型一致。脚本对已知跨控制表的scope提供外键；用户、仓库、分支的既有外键与软删除政策由H0真实DDL映射，不臆造旧字段。缺失/不同字符集必须在副本验证后编写迁移，不能关闭FK检查掩盖。
未引入在线对象GC：本轮开发运行禁止自动删除不可达对象/归档，只允许备份后的离线维护。未来GC必须枚举分支、PR版本/评论锚点、Workline、归档、所有未完成操作的根；否则“对象准备成功→数据库提交”之间会悬空。
