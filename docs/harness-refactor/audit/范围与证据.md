# 本轮输入与证据边界
输入为用户本对话已有的两份完整ZIP：Agent“文档修正与开发导航”包、协作后端与Session同步包；input-manifest.json记录所有输入文件hash。用户确认新重构仅处于协议等早期实现阶段。
本轮没有读取用户最新本地工作树，没有修改远端仓库，没有连接真实MySQL/RabbitMQ/OpenSandbox。旧源码阅读固定提交和窗口保留在03/10/17，它们不是当前本地实现完成证据。
本轮可以检查：资料间冲突、字段/枚举/Schema/示例/参考类型与DDL对应、设计状态的有限反例、文档链接与编译、独立本机探针。
本轮不能证明：生产代码正确、任意竞态无误、真实磁盘断电耐久、容器多租户安全、可在指定小时完成、任何模型等级都不会误解。实际执行结果见07；验收清单所有产品用例初始为NOT_RUN。
本轮新增的技术裁决均登记在audit/修正登记.md，与两份输入的原文事实分开。未验证的设备/SDK/数据库细节保留明确实测门槛，不让静态PASS替代实机。

本轮后续手工复核还补了Submit.worklineStatus运行事实与通知read版本；这些是明确的新契约修正，不是从输入文件抽取出的已有实现。样例日期和摘要为合成测试数据。
