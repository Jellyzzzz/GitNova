# 04｜唯一文件与施工地图

机器清单为[contracts/file-plan.json](contracts/file-plan.json)。本文件由同一清单生成；不是两套创建列表。所有PLANNED类型在用户写出前都不存在，EXISTING_HISTORICAL只表示此前读到历史源码。

**“步骤/段”是职责与施工卡位置，不是要求先写完所有前序文件。** 实际顺序按02开头的“先Core，再托管衔接”导航：协议基础已完成后先做步骤3的Core执行链，再接步骤2/4/5的本地能力，继续完成Worker、平台、发布、恢复与整体验收。步骤1内部仍为CommandType→AgentCommand→ProtocolJson→命令往返→CommandReceipt→EventType→AgentEvent；查询/快照/平台协议类型在步骤6/8/9首次消费前补齐。分步不缩减此表约定的实现责任。

既有源码位置与退役证据保留在[旧源码路径](contracts/old-source-paths.json)、[迁移地图](contracts/migration-map.csv)、[既有文件改动](contracts/existing-edits.json)。旧列表作为定位输入，不能按命中名称自动删除。
