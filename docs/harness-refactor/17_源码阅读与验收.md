## 3. 每次阅读的具体目标

P1先读GN2/GN3，写出“路径与blob能还原哪棵树”；P2读O2→O1→O3，只跟一次create；P3读O5，辨认版本记录与当前源HEAD；P6对照G5的意图与重试；U2/U3读G1/G2小文件；U4读G3；E/N读G4→G6→G7→G8。不要从全仓库数千个类开始读。

每个方法记录五句话：谁调用；输入哪些受信身份；读写哪些事实；哪个步骤可能已发生；错误时靠什么核对。仅看到@Transactional不推导文件系统一起回滚；仅看到消息队列不推导exactly-once；仅看到SELECT再INSERT不推导并发无竞态。

GitHub网页使用文件搜索符号即可。本地已经有固定checkout时再使用：

```bash
rg -n 'void open|void merge|findOpen|checkUpdate' server-core/src/main/java/io/onedev/server
rg -n 'recordMergeIntent|hasPullRequestCommitBeenMerged|NewPullRequest' services/pull
rg -n 'FollowUser|UnfollowUser|StarRepo|WatchRepoWithOptions' models
rg -n 'CreateOrUpdateIssueNotifications|GetRepoIgnorersIDs' services models
# GitNova：在你实际重构分支运行，不在开源项目目录运行
rg -n 'class TransferService|compareAndSetHead|requireReadAccess|requireWriteAccess|Outbox|RabbitTemplate' src
```

JGit网页Javadoc入口前轮访问失败，已改用JG1固定源码核对merge参数顺序。其他方法如MergeFormatter实际签名仍需在已选版本查看；文档给的是明确查询目标，不冒充它已在GitNova编译过。

## 4. 测试目录与运行方式

生产文件对应测试放相同模块的src/test/java同包；跨功能验收放 `src/test/java/com/gitnova/collaboration/`。Fake仅在test。使用独立MySQL测试库或已有容器测试设施，不在实际仓库数据上练删除/权限变更。

建议在根pom新增 `collaboration-it` profile，选择JUnit Tag `collaboration-it`；新增服务器集成测试带该Tag。先核对原Surefire排除规则，不能让旧profile排掉所有新测试。配好后：

```bash
./mvnw -Pcollaboration-it -Dtest=PullRequestIT,SessionSyncIT test
./mvnw -Pcollaboration-it -Dtest=SocialRelationIT,NotificationIT test
```

这些是要创建的测试与profile，不是声称旧仓库已存在。必须检查surefire-reports的执行数和failure/skipped。两连接并发事务测试不可用单线程Mock替代；Broker停机/confirm响应丢失和Sandbox恢复需要各自实机证据。

## 6. 本次统一审计的新外部核验

本次没有重新通读两仓库；沿用上面的固定源码窗口。为审查契约，另核对了[Java21 FileChannel](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/nio/channels/FileChannel.html)、[Files.move](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/nio/file/Files.html)、[MySQL一致性读](https://dev.mysql.com/doc/refman/8.0/en/innodb-consistent-read.html)、[Spring事务代理](https://docs.spring.io/spring-framework/reference/data-access/transaction/declarative/annotations.html)、[RabbitMQ confirms](https://www.rabbitmq.com/docs/confirms)。

对应结论仅限API/协议性质：force不能替代异机备份；多个目录移动不构成一个事务；原子移动覆盖已存在目标行为不能盲信；普通一致性读不等于当前锁定读；自调用可能绕过事务代理；confirm不代表消费者完成或全部预期bindings正确。实际项目版本、MySQL/容器效果仍待实测。索引没有覆盖到的源码方法只列作检索目标，不称已审核实现。
